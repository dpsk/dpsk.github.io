# Demo recordings

One recording per platform and language, named `<platform>-<lang>.<ext>`:

- platform: `windows`, `mac`, `omarchy`
- lang: `en`, `ru`
- `.mp4`: H.264, 1920 px wide, no audio, ~25 s; for the site (`<video autoplay muted loop playsinline>`).
- `.gif`: 800 px wide, 8 fps; for the app READMEs, which link here so the GIFs stay out of the app repositories.

Recorded with a landscape-genre filter, so no nudes show up. The top bar is cropped out.
