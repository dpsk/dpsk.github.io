# dpsk.github.io

Site for [Museum Wallpapers](https://dpsk.github.io/): endless public-domain paintings as your wallpaper, for
[Windows](https://github.com/dpsk/museum-wallpapers-windows) and [Omarchy](https://github.com/dpsk/omarchy-museum-wallpapers).

Static HTML served by GitHub Pages from `master`. The previous site lives in the `archive` branch.
