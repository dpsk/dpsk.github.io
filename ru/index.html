Бесконечная прогулка по картинам из музеев мира, перешедшим в общественное достояние. Новая каждый час, а название, автор и история — в один клик.

Есть и для Omarchy: установить плагин

Бесплатно, открытый код · Windows 10 и 11 · macOS 13+ · Omarchy 4

Знайте, на что смотрите.

У каждой картины есть своя табличка. Нажмите на значок в трее или в строке меню — откроется карточка: название, автор, год и музей, а ещё история картины из Википедии.

  • Дальше, Подробнее, Сохранить. Сразу перейти к следующей, открыть статью или сохранить картину вместе с подписью.
  • Ещё Караваджо. Один клик — и прогулка сужается до одного художника или направления.
  • На вашем языке. Названия и истории из той Википедии, которую вы читаете. Интерфейс — на десяти языках, включая русский и украинский.
  • Табличка на стене. Маленькая музейная подпись в углу рабочего стола — или без неё.

Установка.

Те же картины, подписи и фильтры на всех платформах.

Windows

Windows 10 или 11 · приложение в трее · обновляется через Store

  1. Установите его из Microsoft Store.
  2. Первая картина появится через несколько секунд. Значок в золочёной рамке — рядом с часами.
Скачать в Microsoft Store

Хотите скачать напрямую? Установщик есть на GitHub Releases. Он не подписан, поэтому Windows может предупредить: нажмите Подробнее → Выполнить в любом случае. Ставьте что-то одно, не обе версии сразу. Исходники на GitHub.

macOS

macOS 13 Ventura или новее · приложение в строке меню · обновляется само

  1. Скопируйте команду установки и выполните её в Терминале. Она скачает версию для вашего Mac, проверит её и положит в «Программы».
  2. Первая картина появится через несколько секунд. Значок-рамка — в строке меню.
curl -fsSL https://raw.githubusercontent.com/dpsk/museum-wallpapers-macos/main/install.sh | bash

Удобнее .dmg? Сборки для Apple silicon и Intel есть на GitHub Releases — перетащите приложение в «Программы». Оно не нотаризовано, поэтому при первом запуске откройте Системные настройки → Конфиденциальность и безопасность и нажмите кнопку «Открыть» рядом с сообщением о Museum Wallpapers. Исходники на GitHub.

Omarchy

Omarchy 4 · плагин оболочки · виджет на панели

  1. Установите его из Omarchy Plugin Marketplace. Он запустит сервис и добавит виджет на панель.
  2. Первая картина появится в течение минуты. Карточка — по клику на значок палитры.
Установить из Marketplace

Предпочитаете терминал? То же самое одной командой:

omarchy plugin add https://github.com/dpsk/omarchy-museum-wallpapers --enable
Исходники и настройки на GitHub

Общается только с Викимедиа и ничего о вас не отправляет.
